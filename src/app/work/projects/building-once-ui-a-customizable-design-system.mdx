## Overview

Development of a custom Shopify app that helps merchants increase average order value by motivating customers with a real-time free shipping progress bar on the cart page, paired with a fully configurable admin settings panel.

## Key Features

- **Live Progress Bar**: Built a dynamic, real-time progress bar as a Theme App Extension, showing customers exactly how much more they need to spend to unlock free shipping.
- **Dynamic Messaging**: Implemented customizable pre- and post-unlock messages (e.g. "Add $12 more for free shipping!" → "You've unlocked free shipping! 🎉") that update instantly as the cart changes.
- **Merchant Admin Panel**: Designed a settings interface using Shopify Polaris, allowing merchants to configure the free shipping threshold, custom messages, and progress bar colors — all with a live preview before publishing.
- **Seamless Storefront Integration**: Used Shopify's Theme App Extension architecture so the feature installs directly into any store's theme without manual code edits.

## Technologies Used

- **Remix**: For building the app's admin dashboard and backend logic.
- **Shopify Polaris**: For a native-feeling, accessible merchant admin UI.
- **Shopify Admin API (GraphQL)**: For reading/writing merchant settings.
- **Prisma + SQLite/PostgreSQL**: For storing app configuration data.
- **Shopify CLI & Theme App Extensions**: For storefront integration and local development.

## Challenges and Learnings

One key challenge was syncing merchant-configured settings in real time between the admin panel and the storefront cart, without slowing down the customer experience. This meant carefully structuring data fetches through the Shopify Admin API and optimizing how the Theme App Extension reads cart state. Working through Polaris's component system — including the distinction between Polaris React components and native web components — was also a valuable learning experience in building production-grade Shopify admin interfaces.

## Outcome

The app delivers a smooth, real-time customer incentive directly on the cart page while giving merchants full control over messaging and design — with no code required. It stands as a practical demonstration of end-to-end Shopify app development, from Admin API integration to customer-facing storefront features.
